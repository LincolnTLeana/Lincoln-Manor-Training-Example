# Rollout and communication kit

*Fill in the brackets. Have the wording reviewed (and approved by your manager if AI helped draft it) before sending.*

## Launch checklist
- [ ] All ADP tests passed on the final version ([Testing in ADP Learning](08-testing-in-adp-learning.md))
- [ ] Subject expert, compliance and security review signed off (hand-off form)
- [ ] HR L&D has moved the course to the live catalog and set enrollment and due dates
- [ ] Shared ADP custom report built, tested and shared ([SCORM and ADP reporting](07-scorm-and-adp-reporting.md))
- [ ] Helpdesk and Learning Center told the launch date and given the FAQ
- [ ] Managers have their talking points
- [ ] Announcement scheduled; reminder scheduled for [DATE]
- [ ] Owner named for questions and fixes after launch

## Announcement email
**Subject:** New in ADP Learning: [COURSE TITLE] ([MINUTES] minutes)

> Hi [TEAM],
>
> A new short course, **[COURSE TITLE]**, is now in ADP Learning. It's a game: you explore [4] rooms, learn the key points and answer a few questions in each one. It takes about [MINUTES] minutes, and you can save and come back any time.
>
> **Please complete it by [DATE].**
>
> **Where:** ADP Learning → My Learning
> **Technical problems** (won't open, progress not saved): IT Helpdesk (helpdesk@example.org, 555-0100)
> **Questions about the content:** Learning Center (learningcenter@example.org)
>
> Thank you,
> Training and Development team

## Reminder email
**Subject:** Reminder: [COURSE TITLE] due [DATE]

> Hi [NAME/TEAM], a quick reminder that **[COURSE TITLE]** is due on [DATE]. If you started already, open it in ADP Learning and choose **Continue** to pick up where you left off. Need help? Technical issues: IT Helpdesk (helpdesk@example.org, 555-0100). Content questions: Learning Center (learningcenter@example.org).

## Manager talking points
1. **What:** a short, game-style course in ADP Learning: [COURSE TITLE].
2. **Why:** [ONE SENTENCE ON WHY IT MATTERS TO THE TEAM].
3. **Time:** about [MINUTES] minutes; progress saves, so it can be done in parts.
4. **When:** due [DATE].
5. **Help:** technical issues go to the Helpdesk; content questions go to the Learning Center.

## FAQ
| Question | Answer |
|---|---|
| How long does it take? | About [MINUTES] minutes. |
| Can I stop and come back? | Yes. Choose **Save & exit**, then **Continue** next time. |
| Do I have to pass? | [No: finishing every room completes it. / Yes: you need [X]%. You can choose Start over to try again, and your completion is kept.] |
| What's the secret room? | A bonus for a perfect score. It's just for fun and doesn't affect your score. |
| Does it work on my phone? | Yes, in ADP Learning on a phone or tablet. |
| Is there music? | Optional. It starts off; use the Music button. |
| I finished, but it says In progress. | Make sure every room shows **Complete**, then contact the Helpdesk. |
| A link won't open. | Some pages need you to sign in. Try opening it in a new browser window; if it still fails, tell the Helpdesk which link. |
| I need an accessible format. | Contact Learning Center (learningcenter@example.org). |
| Was AI used to make this? | Yes, AI tools helped draft it, and people reviewed every part. |

| Issue | Goes to |
